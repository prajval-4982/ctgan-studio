Evaluation Suite

Know your data is real enough.

Five evaluation modules run automatically after generation — covering statistical fidelity, privacy leakage, and downstream ML utility.

Statistical Fidelity

Side-by-side comparison of means, standard deviations, and correlation heatmaps between real and synthetic datasets. Column-level distribution plots for every feature.

All models
Feature Importance Alignment

Random Forest models trained on both real and synthetic data — proves the synthetic dataset has preserved the underlying feature logic and relative importance rankings.

All models
ML Utility Scoring

Benchmarks synthetic data against real data using Logistic Regression, Decision Trees, and Random Forests. Reports F1-scores across all three classifiers.

All models
DCR Privacy Audit

Distance to Closest Record analysis. Detects memorization or data leakage by measuring how close synthetic rows are to actual training records in feature space.

All models
Membership Inference Attack Audit DP-CTGAN only

Black-box Membership Inference Attack using a shadow Random Forest classifier. Measures whether an adversary can determine if a record was in the training set — target accuracy ≤ 60%.
